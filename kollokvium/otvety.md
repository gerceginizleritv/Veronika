## Ответы к коллоквиуму по методике преподавания РКИ

### 1. Какая особенность именительного падежа в предложно-падежной системе?

Именительный падеж — **единственный падеж, который не употребляется с предлогами**. Все остальные пять падежей сочетаются с предлогами, а предложный вообще без предлога не употребляется (отсюда и его название).

Другие особенности:

* это **прямой** падеж, все остальные — косвенные;
* это исходная, словарная форма слова;
* основные значения — субъект действия (подлежащее) и название предмета (*Это книга*);
* в РКИ с него начинают изучение падежной системы — «падеж 1».

---

### 2. Какое значение родительного падежа является основным? В каких ещё значениях он выступает?

**Основное значение — определительное (принадлежность, отношение одного предмета к другому):** *книга брата, центр города, крыша дома*. Родительный — самый «приимённый» падеж, он чаще других определяет существительное.

Другие значения:

| Значение | Примеры |
|---|---|
| отсутствие, отрицание | *нет времени, не было денег, не вижу брата* |
| наличие (у кого) | *у меня есть книга* |
| количество, мера | *много людей, пять книг, стакан воды* |
| место, исходная точка (откуда?) | *из Москвы, с работы, от друга, около дома* |
| время | *пятого мая, после урока, во время лекции, до обеда* |
| объект при некоторых глаголах | *бояться собаки, ждать автобуса, желать счастья* |
| сравнение | *старше брата, больше дома* |

---

### 3. Какие падежи имеют значение места?

**Значение места могут выражать все падежи, кроме именительного.** Основной падеж места — предложный.

| Падеж | Предлоги | Примеры | Вопрос |
|---|---|---|---|
| **Предложный** | в, на | *в комнате, на столе* | где? |
| **Винительный** | в, на, за, под, через | *в комнату, на стол, через улицу* | куда? |
| **Родительный** | из, с, от, у, около, возле, напротив, мимо | *из комнаты, с работы, у окна, около дома* | откуда? где? |
| **Творительный** | над, под, перед, за, между, рядом с | *над столом, перед домом, рядом с окном* | где? |
| **Дательный** | к, по | *к другу, по улице* | куда? где? |

---

### 4. Какие падежи выражают состояние субъекта?

| Падеж | Конструкция | Примеры |
|---|---|---|
| **Дательный** (основной) | безличное предложение с предикативным наречием | *Мне холодно. Мне грустно. Ему весело. Мне неудобно.* |
| **Винительный** | безличный глагол (физиологическое состояние) | *Меня тошнит. Его знобит. Её трясёт.* |
| **Родительный** с предлогом *у* | *у кого* + состояние | *У меня болит голова. У него грипп.* |
| **Именительный** | с прилагательным, причастием | *Я рад. Я устал. Он болен.* |

Главный из них — **дательный субъекта** в безличном предложении: именно он специально предназначен для выражения состояния.

---

### 5. Приведите примеры определительных значений разных падежей

Определительное значение — признак предмета, отвечает на вопрос **какой? чей?**

* **Родительный:** книга брата, центр города, человек высокого роста, платье из шёлка, дом без окон
* **Дательный:** памятник Пушкину, экзамен по русскому языку
* **Винительный:** дом в пять этажей, комната в два окна
* **Творительный:** девушка с голубыми глазами, кофе с молоком, дом с балконом
* **Предложный:** человек в очках, книга о России, дом на берегу

---

### 6. Как и в каких падежах выражается время?

| Падеж | Средство | Примеры |
|---|---|---|
| **Винительный** | в + В. п. | *в понедельник, в среду, в два часа* |
| | через + В. п. | *через час, через неделю* |
| | без предлога | *всю неделю, целый день, каждый день* |
| | за + В. п. (срок выполнения) | *сделал за два часа* |
| | на + В. п. (на какой срок) | *приехал на два дня* |
| **Родительный** | без предлога (дата) | *пятого мая, двадцать первого года* |
| | после, до, во время, в течение | *после урока, до обеда, в течение года* |
| | с … до | *с утра до вечера* |
| **Дательный** | по + Д. п. мн. ч. (регулярность) | *по понедельникам, по вечерам* |
| | к + Д. п. (не позже чем) | *к вечеру, к пяти часам* |
| **Творительный** | без предлога | *утром, днём, вечером, ночью, весной, летом* |
| | перед, между, за | *перед обедом, между лекциями, за работой* |
| **Предложный** | в + П. п. | *в январе, в этом году, в детстве* |
| | на + П. п. | *на этой неделе, на прошлой неделе* |

Именительный падеж значения времени не выражает.

---

### 7. Приведите примеры объектных значений падежей

Объектное значение — предмет, на который направлено действие.

* **Винительный** — прямой объект, главное объектное значение: *читать книгу, видеть друга, любить музыку*
* **Родительный** — объект при отрицании (*не вижу брата*), при некоторых глаголах (*бояться собаки, ждать автобуса, достичь цели*), часть целого (*выпить чаю*)
* **Дательный** — адресат: *писать другу, сказать брату, помогать маме, звонить сестре*
* **Творительный** — орудие (*писать ручкой, резать ножом*); объект при глаголах (*заниматься спортом, интересоваться музыкой, руководить отделом*); субъект в пассиве (*написан студентом*)
* **Предложный** — объект речи и мысли: *говорить о фильме, думать о работе, рассказывать о поездке*

### 8. Определите падеж существительных и в каком значении они выступают

**Маша с радостью отвечала на вопросы матери.**

| Слово | Падеж | Значение |
|---|---|---|
| Маша | именительный | субъект действия (подлежащее) |
| с радостью | творительный с предлогом *с* | образ действия (как?) |
| на вопросы | винительный с предлогом *на* | объектное (отвечать на что?) |
| матери | родительный | определительное — принадлежность (чьи вопросы?) |

**Мне неудобно сидеть рядом с окном.**

| Слово | Падеж | Значение |
|---|---|---|
| мне | дательный | субъект состояния (дательный субъекта в безличном предложении) |
| с окном | творительный с предлогом *рядом с* | место (где?) |

**У меня нет брата.**

| Слово | Падеж | Значение |
|---|---|---|
| у меня | родительный с предлогом *у* | субъект обладания (у кого?) |
| брата | родительный | отсутствие (при слове *нет*) |

**Комната сестры самая тёплая.**

| Слово | Падеж | Значение |
|---|---|---|
| комната | именительный | субъект (подлежащее) |
| сестры | родительный | определительное — принадлежность (чья комната?) |

**Пока я школьник, но осенью стану студентом университета.**

| Слово | Падеж | Значение |
|---|---|---|
| я | именительный | субъект |
| школьник | именительный | предикативное (именная часть сказуемого) |
| осенью | творительный без предлога | время (когда?) |
| студентом | творительный | предикативное (творительный предикативный при глаголе *стать*) |
| университета | родительный | определительное (какой студент?) |

### 9. В чём основное различие в значениях НСВ и СВ? С какого значения начинают работу по этой теме?

**Различие.** Совершенный вид представляет действие как **целостный факт, ограниченный пределом**, — с результатом или завершением. Несовершенный вид на предел не указывает: он обозначает действие в процессе, повторяющееся или сам факт действия.

Короткая формулировка: СВ отвечает на вопрос *что сделал?* и говорит о **результате**; НСВ — *что делал?* и говорит о **процессе или повторении**.

Основные частные значения:

* **НСВ:** процесс (*Я читал весь вечер*), повторяемость (*Я часто читаю*), общефактическое (*Вы читали эту книгу?*)
* **СВ:** конкретный единичный результат (*Я прочитал книгу*), начало действия (*запел*), ограниченная длительность (*посидел*)

**С чего начинают.** Работу начинают **с несовершенного вида — со значения процесса и повторяющегося действия**, потому что формы настоящего времени есть только у НСВ, и первые глаголы (*читать, писать, делать, говорить*) учащийся усваивает именно в настоящем времени.

Само противопоставление вводится позже, при введении **прошедшего времени**: *делал — сделал*, то есть «процесс или повторение» против «результата».

### 11. Какую функцию выполняют причастия в сложноподчинённом предложении?

Причастный оборот **заменяет придаточное определительное предложение со словом *который***. Сложноподчинённое предложение превращается в простое с обособленным определением.

* *Студент, **который читает** книгу* → *Студент, **читающий** книгу*
* *Книга, **которую прочитал** студент* → *Книга, **прочитанная** студентом*

Функция — **компрессия (сжатие) предложения**. Это средство книжно-письменной речи, прежде всего научного стиля.

**Важное ограничение.** Замена возможна только тогда, когда слово *который* стоит:

* в именительном падеже — тогда употребляется **действительное** причастие;
* в винительном падеже без предлога — тогда **страдательное**.

Если *который* стоит в другом падеже или с предлогом, замена невозможна: *дом, **в котором** я живу* причастием заменить нельзя.

### 12. Роль деепричастия в предложении

Деепричастие обозначает **добавочное (второстепенное) действие** при основном, выраженном глаголом-сказуемым.

**Главное условие: оба действия совершает один и тот же субъект.**

Деепричастный оборот заменяет придаточное предложение:

| Значение | Придаточное | Деепричастный оборот |
|---|---|---|
| время | *Когда я шёл домой, я встретил друга* | *Идя домой, я встретил друга* |
| время (предшествование) | *Когда я пришёл домой, я позвонил другу* | *Придя домой, я позвонил другу* |
| причина | *Так как он не знал адреса, он опоздал* | *Не зная адреса, он опоздал* |
| условие | *Если вы будете много работать, вы добьётесь успеха* | *Много работая, вы добьётесь успеха* |

Вид деепричастия задаёт соотношение действий: **НСВ — одновременность** (*идя*), **СВ — предшествование** (*придя*).

Типичная ошибка — разные субъекты у основного и добавочного действия: *Подъезжая к станции, у меня слетела шляпа*.

Как и причастие, деепричастие служит средством **компрессии** и принадлежит книжной речи.

### 13. Особенности глаголов движения без приставок

* Это **14 пар** глаголов: *идти — ходить, ехать — ездить, бежать — бегать, лететь — летать, плыть — плавать, нести — носить, вести — водить, везти — возить, ползти — ползать, лезть — лазить, брести — бродить, тащить — таскать, катить — катать, гнать — гонять*.
* **Оба члена пары — несовершенного вида. Это не видовая пара.**
* Противопоставление идёт по признаку **однонаправленности / разнонаправленности**.
* **Корень обязательно выражает способ передвижения:** пешком (*идти*) или на транспорте (*ехать*). В большинстве языков это различие не выражается, отсюда ошибки типа *«Я иду в Москву»*.

**Значения однонаправленных (идти):**

* движение в одном направлении в определённый момент: *Я иду в университет*;
* ближайшее запланированное будущее: *Завтра я иду в театр*.

**Значения разнонаправленных (ходить):**

* движение в разных направлениях: *Ребёнок ходит по комнате*;
* регулярно повторяющееся движение: *Я хожу в университет каждый день*;
* **однократное движение «туда и обратно» в прошедшем времени**: *Вчера я ходил в театр* (= был и вернулся);
* способность, умение: *Ребёнок уже ходит. Рыбы плавают.*

**Видовые пары** образуются приставкой *по-*, причём с разным значением:
*идти → пойти* (начало движения), *ходить → походить* (недолго).

---

### 14. Глаголы движения с приставками

**Главная особенность: при присоединении приставки оппозиция однонаправленности и разнонаправленности снимается и заменяется видовой.**

| Исходный глагол | С приставкой | Вид |
|---|---|---|
| идти (однонаправленный) | **прийти** | совершенный |
| ходить (разнонаправленный) | **приходить** | несовершенный |

Получается обычная видовая пара: *прийти — приходить*.

**Изменение основ** у разнонаправленных глаголов — требует отдельного запоминания:

* ходить → **-ходить** (приходить)
* ездить → **-езжать** (приезжать)
* плавать → **-плывать** (приплывать)
* лазить → **-лезать** (влезать)

**Приставки пространственные, вводятся антонимическими парами:**
в- / вы-, при- / у-, под- / от-, вз- / с-, со-…-ся / раз-…-ся.
Без прямых антонимов: до-, пере-, про-, за-, об-.

**Приставка работает в комплексе с предлогом и падежом**, и это главная трудность:

* войти **в** что? (винительный) — выйти **из** чего? (родительный)
* прийти **в/на** что? (винительный), **к** кому? (дательный)
* подойти **к** чему? (дательный) — отойти **от** чего? (родительный)
* дойти **до** чего? (родительный)

**Особый случай: с- + разнонаправленный глагол = совершенный вид** со значением однократного движения «туда и обратно»: *сходить, съездить, сбегать, слетать*. Это нарушение общего правила, его нужно запоминать отдельно.

**Аннулирующее значение НСВ** в прошедшем времени: *Ко мне приходил друг* = пришёл и ушёл (результат отменён обратным движением). Ср.: *Ко мне пришёл друг* — он, возможно, ещё здесь.
