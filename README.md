# Реферат: Глаголы движения как особая категория лексико-грамматической системы русского языка при обучении РКИ

## Структура репозитория

```
referat/
  referat.md        — основной текст реферата
materialy/
  istochniki.md     — рабочие заметки по источникам, статус проверки
```

## Статус работы

| Раздел | Состояние |
|---|---|
| Введение | готово |
| Глава 1 (лингвистическое описание) | готово |
| Глава 2 (методика РКИ) | готово |

Объём основного текста — приблизительно 30 страниц стандартного формата
(1800 знаков с пробелами). При необходимости сокращения см. рекомендации
в `materialy/istochniki.md`.

## Что нужно сделать перед сдачей

1. Проставить постраничные ссылки по печатным экземплярам источников
   (внутритекстовые отсылки сейчас даны в форме `[Автор год]` без страниц).
2. Уточнить выходные данные позиций 10 и 12 списка литературы.
3. Оформить титульный лист по требованиям кафедры.
4. Проверить соответствие оформления списка литературы принятому ГОСТу
   или методическим указаниям вуза.
