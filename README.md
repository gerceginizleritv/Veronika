# Реферат: Глаголы движения как особая категория лексико-грамматической системы русского языка при обучении РКИ

## Что готово

| Требование преподавателя | Состояние |
|---|---|
| Объём не менее 25 страниц | **33 стр.** (31 без приложений) |
| Поля 2 см со всех сторон | выполнено |
| Кегль 14, интервал 1,5 | выполнено |
| Титульный лист | **сделан по стандартной форме — нужно сверить с формой кафедры** |
| Введение — основная часть — заключение | выполнено |
| Список литературы не менее 5 источников | **13 источников** |

## Файлы

```
docx/Referat_Glagoly_dvizheniya.docx  — ГОТОВЫЙ ФАЙЛ ДЛЯ СДАЧИ
docx/Rabochie_zametki.docx            — рабочие заметки (не сдаётся)

referat/referat.md                    — исходный текст
referat/titulnyj_list.txt             — шаблон титульного листа
materialy/istochniki.md               — заметки по источникам
tools/md2docx.py                      — конвертер md -> docx
```

## Что нужно сделать перед сдачей

1. **Заполнить титульный лист** — вместо прочерков вписать название вуза,
   факультет, кафедру, дисциплину, Ф. И. О., данные научного руководителя,
   город. Править можно прямо в Word.
2. **Обновить оглавление** — открыть файл в Word, щёлкнуть по оглавлению,
   нажать F9, выбрать «Обновить целиком». Без этого страницы в оглавлении
   не проставятся.
3. Уточнить выходные данные источников № 10 и № 12 списка литературы
   (см. `docx/Rabochie_zametki.docx`).
4. Проставить постраничные ссылки во внутритекстовых отсылках, если
   кафедра этого требует.

## Пересборка файла после правок

```bash
pip3 install python-docx
python3 tools/md2docx.py referat/referat.md \
        docx/Referat_Glagoly_dvizheniya.docx \
        --title referat/titulnyj_list.txt
```
