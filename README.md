| Требование | Раб. 1 | Раб. 2 | Раб. 3 |

## Что нужно сделать перед сдачей любой работы

1. **Заполнить титульный лист** — вместо прочерков вписать вуз, факультет,
   кафедру, дисциплину, Ф. И. О., данные научного руководителя, город.
   Править можно прямо в Word.
2. Проверить, совпадает ли форма титульного листа с формой кафедры —
   она ни разу не была приложена к заданию, сделана стандартная.

## Пересборка после правок

```bash
python3 tools/md2docx.py referat/referat.md \
        docx/Referat_Glagoly_dvizheniya.docx --title referat/titulnyj_list.txt

python3 tools/md2docx.py referat/govorenie.md \
        docx/Referat_Govorenie.docx --title referat/titulnyj_list_govorenie.txt

        docx/Referat_Grammatika.docx --title referat/titulnyj_list_grammatika.txt
```
