# Рефераты по методике преподавания РКИ

## Работы

### 1. Глаголы движения как особая категория лексико-грамматической системы русского языка при обучении РКИ

Готовый файл: `docx/Referat_Glagoly_dvizheniya.docx` — 33 стр.

### 2. Говорение как цель и средство обучения русскому языку как иностранному

Готовый файл: `docx/Referat_Govorenie.docx` — 32 стр.

| Требование | Работа 1 | Работа 2 |
|---|---|---|
| Объём не менее 25 страниц | 33 | 32 |
| Поля 2 см со всех сторон | да | да |
| Кегль 14, интервал 1,5 | да | да |
| Титульный лист | да | да |
| План | — (не требовался) | да |
| Введение — основная часть — заключение | да | да |
| Список литературы не менее 5 источников | 13 | 5 |

## Что нужно сделать перед сдачей

1. **Заполнить титульный лист** — вместо прочерков вписать вуз, факультет,
   кафедру, дисциплину, Ф. И. О., данные научного руководителя, город.
   Править можно прямо в Word.
2. В работе 1 — **обновить оглавление**: щёлкнуть по нему, нажать F9,
   выбрать «Обновить целиком». В работе 2 вместо оглавления статический
   план, обновлять не нужно.
3. В работе 2 — **выверить по печатному изданию Госстандарта** числовые
   показатели требований к говорению (объём высказывания, темп речи,
   число реплик), если они понадобятся в тексте. Сейчас они намеренно
   не приведены, вместо них стоит оговорка.

## Пересборка после правок

```bash
pip3 install python-docx

python3 tools/md2docx.py referat/referat.md \
        docx/Referat_Glagoly_dvizheniya.docx \
        --title referat/titulnyj_list.txt

python3 tools/md2docx.py referat/govorenie.md \
        docx/Referat_Govorenie.docx \
        --title referat/titulnyj_list_govorenie.txt
```
