# Рабочие договорённости по этому репозиторию

## Формат выдачи файлов

**Все готовые материалы выдавать в формате `.docx`.** Пользователь работает
в Microsoft Word на MacBook Air и не использует markdown-редакторы.

Порядок работы:
1. текст пишется и правится в `.md` (удобно для версионирования и правок);
2. **обязательно** конвертируется в `.docx` скриптом `tools/md2docx.py`;
3. пользователю отправляется именно `.docx`, готовый файл кладётся в `docx/`.

Команда конвертации:

```bash
python3 tools/md2docx.py referat/referat.md \
        docx/Referat_Glagoly_dvizheniya.docx \
        --title referat/titulnyj_list.txt
```

Требуется `pip3 install python-docx` (в свежем контейнере ставить заново).

## Требования к оформлению (заданы преподавателем)

1. Объём — **не менее 25 страниц** (норма 1800 знаков на страницу).
2. Поля — **2 см со всех сторон**, кегль **14**, интервал **1,5**.
3. Структура: титульный лист — введение — основная часть — заключение —
   список литературы (**не менее 5 источников**).

Всё это уже зашито в `tools/md2docx.py`. Дополнительно скрипт делает:
выравнивание по ширине, абзацный отступ 1,25 см, таблицы с сеткой (11 пт),
нумерацию страниц внизу по центру (на титульном листе номер не ставится),
поле автособираемого оглавления по маркеру `<!--TOC-->`, разрывы страниц
по маркеру `<!--PAGEBREAK-->`.

**Титульный лист** — `referat/titulnyj_list.txt`, простой текстовый формат:
`^строка` — по центру полужирным 16 пт, `>строка` — по правому краю,
`~` — пустая строка, остальное — по центру 14 пт. Сейчас в нём прочерки
вместо названия вуза, кафедры, Ф. И. О. — их нужно вписать.

## Язык

Автор работы — носитель русского языка. Вся переписка с ней и все
материалы — **на русском**. Задачи может ставить и муж (по-турецки) —
ему отвечать по-турецки, но файлы всё равно готовить на русском.

## Структура репозитория

```
referat/        — исходные тексты (.md) и шаблоны титульных листов (.txt)
materialy/      — рабочие заметки (не сдаются)
docx/           — готовые файлы для сдачи
tools/md2docx.py — конвертер md -> docx
```

## Требование «план»

Во втором задании преподаватель потребовал отдельный раздел **«План»**
между титульным листом и введением. Это не то же самое, что «Содержание»:
план — статический перечень разделов без номеров страниц. Если в новой
работе такого требования нет, вместо плана ставится маркер `<!--TOC-->`
(автособираемое оглавление Word).
